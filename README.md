# Plain English Law – Victorian law commencements

A free, static calendar of when Victorian law changes (and a few key federal ones) take effect. Each entry has a one-line plain-English summary, who it affects, and a link to the official source.

**General information only, not legal advice.**

This calendar is compiled by a law graduate, not a lawyer.

## Files

- `index.html` — landing page. Subscribe links are built from the page URL.
- `vic_law_commencements.ics` — the subscribable calendar.
- `vic_law_commencements.csv` — the source list.

## How to update

Replace `vic_law_commencements.ics` and `vic_law_commencements.csv`, then commit to `main`. The URL stays the same.
